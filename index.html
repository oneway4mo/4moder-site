4moder

Панель управления
Функционал бота

Модерация

  • Фильтры спама, капса, ссылок.
  • Черные списки по RegEx фразам.
  • Авто-цепочка: Варн -> Мут -> Бан.
  • Разрешения через `!permit`.

Команды и API

  • Динамический аптайм и фолловаж.
  • Права: Стример / Модер / VIP / Саб.
  • Кастомные кулдауны на команды.
  • Внешние запросы через `$(urlfetch)`.

Баллы и Игры

  • Авто-начисление поинтов чату.
  • Магазин ролей и интерактивов.
  • Игры, дуэли `!duel` и рулетка.
  • Топ лидеров по времени просмотра.

Автоматизация

  • Таймеры рекламы по таймингу/строкам.
  • Розыгрыши (Giveaways) в один клик.
  • Заказ музыки YouTube/Spotify.
  • Вебхуки уведомлений в Дискорд.
